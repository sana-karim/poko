# POKO

### A tiny life on your desk.

POKO is a small ESP32-S3 powered digital desk companion.

## Features

- 👀 Animated eyes
- 😴 Sleep / wake
- 😊 Happy expression
- 😠 Angry expression
- 👆 Touch reactions
- 🔊 Sounds
- 🌤️ Wi-Fi + weather
- 🔋 Battery powered
- 🔄 OTA updates
- 🏠 Custom 3D-printed enclosure

## Hardware

- ESP32-S3
- 1.3" 128×64 SH1106 OLED
- Touch sensor
- Speaker
- Li-Po battery
- 5V boost converter

## Current status

OLED and animated eye prototype working.
